## What's new in 0.79.0: a progress bar while a server downloads its mods

Closes [#235](https://github.com/tubalainen/reforger-server-manager/issues/235).

- **A starting server shows its mod download.** On a first start, the Arma server
  downloads the template's Workshop mods before it logs anything useful, so the
  console looked stuck for minutes. The **Overview** and **Console** tabs now show
  a progress bar while the server is starting, for example *Downloading mods:
  1.20 GB of 3.40 GB · 35 %*, with the download speed and how many mods (with
  their dependencies) it is fetching.
- **The total comes from the Workshop.** The manager looks up the template's mods
  and everything they depend on, in the background, and counts a shared
  dependency once. If the Workshop does not answer, the bar still moves and shows
  how much has been downloaded so far.
- **When the download stops growing,** the bar turns green: *Mods downloaded —
  loading the world…*. It disappears once the server is online.

The bar measures the same folder as **Settings → Maintenance → Downloaded &
baked mods**. A server that already has its mods from an earlier run starts part
of the way along, or goes straight to "loading the world".

## Do I need to do anything?

**No.**
