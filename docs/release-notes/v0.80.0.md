## What's new in 0.80.0: `rsm cli`, the servers in a terminal

Closes [#237](https://github.com/tubalainen/reforger-server-manager/issues/237).

- **`sudo rsm cli` shows every stack's game servers in the terminal.** Each
  server's state (online, starting, stopped), players online and player limit,
  FPS, CPU, memory and uptime, with the totals underneath and the machine's load
  and memory on top. It refreshes every 5 seconds. A stack whose manager is down
  says so, with the command that starts it.
- **Start, stop and restart from there.** Select a server with the arrow keys,
  then press `s`, `x` or `r`. A stop or restart asks first and names the players
  still on it. Each one is done by that stack's own manager, exactly as a click
  in its GUI, so the team sees it and a stopped server is not mistaken for a
  crash and started again.
- **`rsm cli --once`** prints the table once and exits, for scripts and
  cron mails. `--stack NAME` shows one stack only.

It needs only `rsm` and the stacks' managers, not the Server Supervisor, whose
page stays read-only. See [The servers in a terminal](https://github.com/tubalainen/reforger-server-manager/blob/main/docs/installation.md#the-servers-in-a-terminal-rsm-cli).

## Do I need to do anything?

**Linux:** `sudo rsm update --all` brings the new `rsm` and updates every
stack's manager. A stack still on an older manager is listed as *its manager
predates rsm cli* until it is updated. Windows has no `rsm`, so nothing changes
there.
