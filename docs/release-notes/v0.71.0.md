## What's new in 0.71.0: open a mod's Workshop page from its id

Every mod id shown under a mod's name is now a link to that mod's page on the
Arma Reforger Workshop, so its description, dependencies and changelog are one
click away. The page opens in a new tab, so you don't leave the editor.

It works in:

- the **Mods** step of a server template, including the previews when you add a
  mod list or take an AI load order,
- the **Mod lists** editor,
- the **Mods Overview** tree (on wider screens, where the id is shown).

In a server template the mod rows can still be dragged to change the load order;
a drag that starts on the id moves the row as before.

## Do I need to do anything?

**No `.env` or compose change.** Update as usual. On Linux:

```bash
sudo rsm update
```

On Windows, run the start shortcut as usual; it pulls the new image.
