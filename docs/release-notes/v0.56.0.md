## What's new in 0.56.0: a new way around the manager

The first step of the GUI rework in
[#189](https://github.com/tubalainen/reforger-server-manager/issues/189). This release
changes **where things are**, not what they do. Every page and every button is still
there.

## Do I need to do anything?

**No.** No `.env` or compose change. Servers, templates and backups are untouched.
Bookmarks and old links keep working: every old address forwards to the page's new
home.

## Three places instead of six tabs

The row of six tabs across the top is gone. A narrow menu down the left edge has
three destinations, with Help at the bottom:

| Menu | What's in it | Where it used to be |
|---|---|---|
| **Servers** | your server instances and each server's page | Instances |
| **Library** | Server templates · Mod templates · Mods overview | Templates, Mod Templates, Mods |
| **System** | Server files · Ports & firewall · Export & import | bottom of Instances, Backup |
| **Help** | the user guide | Guide |

Library and System show a row of links along the top to move between their pages.
The template wizard sits under Library › Server templates, so that is what stays lit
while you edit.

On a phone or a narrow window the same menu becomes a bar along the bottom of the
screen.

## Server files and the firewall moved to System

Both used to sit on the Instances page. They describe the machine rather than any
one server, so they now have their own pages: **System › Server files** and **System ›
Ports & firewall**. The firewall panel is always open there instead of folded away.

When the daily check finds a new server release, the prompt on the Servers page
is still there, and its **Update server files** button still starts the download. It
then takes you to System › Server files to watch progress. **System** in the menu
also shows a count, so you notice the update from any page.

## "Backup" is now "Export & import"

The old **Backup** tab exported and imported your *templates*. A server's saved-game
backups lived on the server's own page, so two different things were called
"backup". The template page is now **System › Export & import**. It works exactly as
before.

## Smaller changes

- The live server chips in the old top bar are gone. Server status is on the Servers
  page, which keeps its own status bar, and gets a proper overview in the next step
  of #189.
- The version number and the GitHub link sit at the bottom of the menu, and at the
  end of the System links on a phone.
- Any unknown address now lands on Servers instead of a blank page.
- The Guide, README and feature list point to the new places.
