## What's new in 0.76.0: delete a template that servers use

Asked for on [#223](https://github.com/tubalainen/reforger-server-manager/issues/223).
A server template can now be deleted even while servers use it, stopped or
running. Before, the delete was refused until every server on it had been
deleted or switched to another template.

- **You are told what happens first.** **Delete** names each server that uses
  the template, and which of them are running. A Prod template still asks a
  second time.
- **Running servers are shut down.** Once you confirm, each server on the
  template is unlinked from it and stopped. Crash recovery, daily restarts and
  automatic update restarts leave it alone from then on.
- **No template selected.** Those servers stay, with their saves, backups,
  ports and settings. They show **No template selected** in the server list
  and on their own page, and each gets an item under *Needs attention* with a
  **Choose a template** button. They cannot start until a template is chosen
  under **Settings**, which works as it always has.

## Do I need to do anything?

**No.** The first start of v0.76.0 updates the manager's database by itself,
once: a server can now be without a template. Nothing else changes, and no
server is touched.
