## What's new in 0.72.0: Test, Dev and Prod for templates and mod lists

Server templates and mod lists now move through three stages, so it is always
clear which ones are the golden copies and which are still being worked on
(#223).

- **Test**: free to change. Every new template and mod list starts here.
- **Dev**: being tested on real servers. Still editable, and every save asks
  for a short comment that goes into the change log.
- **Prod**: released and locked. A Prod template can be viewed, copied and
  deleted, never changed. Deleting one asks twice.

Things only move upwards. On the list pages, **To Dev** moves a Test item on,
and **Release…** puts a Dev item in Prod. The pages group everything under Prod,
Dev and Test.

### Versions

Every release to Prod is a version: v1, v2, and so on. To change a Prod
template:

1. Copy it (**Copy to Test** in its ⋯ menu, or on its page). The copy lands in
   Test and remembers where it came from.
2. Change it, and move it to Dev for testing.
3. **Release…** it as the *next version of* the original. The original keeps
   its name and becomes v2. The copy is used up and its change log moves over.

Servers on the original pick up the new version on their next restart, as they
always have after a template change. **+ New template › Based on a Prod
template…** starts a change the same way.

Servers can run a template of any stage. The servers list and each server's
page show the template's stage, such as **Prod v2**.

### Also

- The template list's row buttons moved into a ⋯ menu: change log,
  config.json, copy, to mod list and delete.
- Mod lists can now be copied.
- A backup file now carries each template's stage and, for Prod, every
  version. An import can't overwrite a Prod template; it can import the file's
  version beside it, as a copy in Test.
- The Mods overview's *Add selected to template…* leaves Prod templates out.

## Do I need to do anything?

**No `.env` or compose change.** Update as usual. On Linux:

```bash
sudo rsm update
```

On Windows, run the start shortcut as usual; it pulls the new image.

After the update, every template and mod list you already have is in **Dev**:
nothing is called golden until you release it. Your servers keep running
exactly as before. Release the ones you trust to Prod, one click each; they
become v1.
