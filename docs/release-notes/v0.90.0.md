## What's new in 0.90.0: RCON command lists, named navmeshes, and a working Cross-platform switch

### Cross-platform off now means PC only

Bohemia's Server Config page gives two valid combinations: `crossPlatform`
**on** with all three platforms, or **off** with PC only. The manager always
wrote all three platforms to `supportedPlatforms`, whatever the switch said.
With `crossPlatform` off the engine reads `supportedPlatforms`, so **unticking
Cross-platform changed nothing**: Xbox and PlayStation players could still
join.

The manager now writes `supportedPlatforms` to match the switch:

- **on:** `["PLATFORM_PC", "PLATFORM_XBL", "PLATFORM_PSN"]`, as before;
- **off:** `["PLATFORM_PC"]`.

A platform list typed in with Edit JSON (anything other than all three) is
kept while the switch is off.

**This takes effect the next time a template is saved.** A template with
Cross-platform unticked that is saved after updating will stop letting console
players in. That is what the switch always said, but it is new behaviour for
anyone who relied on it not working. A template with Cross-platform ticked
writes exactly what it did before.

### New in Advanced settings

- **RCON › Blocked commands** (`rcon.blacklist`): RCON commands that may not
  be run, one per line.
- **RCON › Allowed commands** (`rcon.whitelist`): when this lists any command,
  RCON may run only those. Leave it empty to allow every command.
- **Operating › Only these navmeshes** (`operating.disableNavmeshStreaming`),
  under *Disable navmesh streaming*: navmesh names, one per line, for example
  `Soldiers` or `BTRlike`. Leave it empty for every navmesh, the same as
  before. This needs Arma Reforger 1.2.0 or later.

All three are written only when they hold something, so a template that
doesn't use them writes the same config.json as before. A list you had
already typed in with Edit JSON now shows up in these fields, and editing it
there takes effect.

### Help texts checked against the wiki

The help tips added in 0.89.0 were written without the wiki. They are now
checked against it, and several are corrected:

- Disable auto-shutdown (it covers a lost connection to Bohemia's backend)
- Fast validation
- Lobby player sync (it reports the real player count to the server browser)
- Slot reservation timeout (it covers kicked players; 5 turns it off)
- Cross-faction VON (off means listen-only)
- AI limit
- Navmesh streaming
- Mods required by default

Cross-platform on the Server card has a "?" of its own.

## Do I need to do anything?

If any of your templates has **Cross-platform unticked** and you want console
players to keep joining, tick it before you next save that template.

## Updating your setup files

No compose file, `.env` setting or script changed. Pull the new manager image:

- **Linux with the installer (`rsm`):** `sudo rsm update --all`.
- **Linux VPS:** the same.
- **Linux, installed by hand:** pull the new manager image and restart it.
- **Windows:** run `.\start.ps1`, which pulls the new manager image.
