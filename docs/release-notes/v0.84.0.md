## What's new in 0.84.0: a clean start after switching templates

When you switch a server to another template (Settings › Template), what is on
its disk still came from the old one: its downloaded mods, its saved game and
its logs. The first **Start** after the switch, from the server's page or the
Servers list, now asks what to clear first:

- **Downloaded & baked mods:** the old template's mods. Cleared, the server
  downloads only the new template's mods.
- **Saved game data:** the old scenario's world. Cleared, the new template
  starts a fresh one. **Back up the saved game first** is ticked by default; the
  backup appears on the Saves tab.
- **Logs & crash reports:** past sessions' logs.

Each shows its size, and nothing is ticked: **Start, keep everything** starts as
before, with the new template's mods downloading next to the old ones. Ticking
anything turns the button into **Clear and start**.

It asks once per switch. Switching back to the template the server last ran
asks nothing, because its data matches again. Starts from `rsm cli`, crash
recovery and the daily restart never ask, and keep everything.

## Do I need to do anything?

No. Existing servers count as last started with the template they have now, so
nobody is asked until they switch.

## Updating your setup files

No compose file, `.env` setting or script changed. Pull the new manager image:

- **Linux with the installer (`rsm`):** `sudo rsm update --all`.
- **Linux VPS:** the same.
- **Linux, installed by hand:** pull the new manager image and restart it.
- **Windows:** run `.\start.ps1`, which pulls the new manager image.
