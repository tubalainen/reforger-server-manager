## What's new in 0.57.0: the Servers overview

The second step of the GUI rework in
[#189](https://github.com/tubalainen/reforger-server-manager/issues/189). **Servers**
used to be a grid of cards; it is now one overview of the whole host.

## Do I need to do anything?

**No.** No `.env` or compose change. Nothing about your servers, templates or backups
changes.

## The whole host at a glance

Across the top are four figures: **servers online**, **players**, and **CPU** and
**memory** across all running servers. Under each is a small line of the last hour.
CPU is each server's share of the whole machine, added up, so 100% means every core
is busy.

The lines start when the manager starts. The manager records one point a minute and
keeps an hour, in memory, so a manager restart starts them over.

## One list of what needs you

Warnings used to be scattered: a yellow box on each card, a banner per update. They are
now one **Needs attention** list, and every line has the one button that deals with it:

| When | The line says | The button |
|---|---|---|
| A template was edited after a running server started | which server and template | **Restart** |
| A branch's server files are not downloaded | which servers that blocks, named once per branch | **Server files** |
| The daily check found a new server release | the build it moves from and to, and which servers still run the old one | **Update server files** |

## A row per server

Each server gets one row: status, **players against the template's limit** (with a
small fill bar), FPS, CPU, memory, uptime and the **next scheduled restart**.
Start, Stop, Restart and Delete sit at the end of the row. Click the name to open the
server.

**Restart all running** restarts every running server at once. It first names the
servers and asks, because it disconnects everyone playing on them.

On a phone each row becomes a small block of labelled figures, with the buttons
underneath.

## Smaller changes

- A server with no container used to be labelled with Docker's word, *absent*. It now
  says **stopped**, here and on the server's own page.
- With no template yet, the page says to start in the Library and offers
  **New template**. With templates but no servers, it offers **New server**.
- `/api/instances/summary` now carries everything the overview shows: template name,
  scenario, player limit, FPS, CPU, memory, uptime, next restart, *template changed*,
  *server files ready*, host-wide CPU and memory totals, and the last hour of totals.
  The page polls that one endpoint instead of two, and it still costs one Docker
  listing however many servers there are.
