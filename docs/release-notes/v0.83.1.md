## What's fixed in 0.83.1

- **Mod lists line up.** On Library › Mod lists, a list with a long
  description (such as "Made from the server template … Scenario mods left
  out: …") pushed its Edit, Release and ⋯ buttons below the text, while lists
  with short descriptions kept them on the right. Every row now keeps its
  buttons on the right, and a long description wraps beside them. On a phone,
  every row puts its buttons under the text.
- The locked-mods badge reads "🔒 3 locked" in a quiet outline instead of a
  white pill, and a list with one mod says "1 mod".

## Do I need to do anything?

No.

## Updating your setup files

No compose file, `.env` setting or script changed. Pull the new manager image:

- **Linux with the installer (`rsm`):** `sudo rsm update --all`.
- **Linux VPS:** the same.
- **Linux, installed by hand:** pull the new manager image and restart it.
- **Windows:** run `.\start.ps1`, which pulls the new manager image.
