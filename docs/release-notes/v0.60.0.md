## What's new in 0.60.0: shorter pages, plainer words

The fifth step of the GUI rework in
[#189](https://github.com/tubalainen/reforger-server-manager/issues/189). No new buttons
this time: less reading on every visit, and the same words for the same things
everywhere.

## Do I need to do anything?

**No.** No `.env` or compose change. Your servers, templates, mod lists and backups are
untouched. Old links to the mod template pages forward to their new addresses.

## Explanations when you ask for them

Several pages opened with a paragraph or two that was useful the first time and in the
way every time after. Each is now **one short line**, and a small **?** next to it opens
the full explanation in place. Click it again, click elsewhere, or press Esc to close
it.

| Where | Now reads | Behind the ? |
|---|---|---|
| A server's **Saves** tab | *Copies of this server's world. Take one before changing its template.* | What a backup holds, and why to take one before a change |
| — while the server runs | *Fine to take while it runs.* | Why a save point written at that moment can be half-finished |
| — under the backups | *The newest 10 are kept.* | Pruning, and why a downloaded copy is the one that survives the machine |
| Saved game on disk / Maintenance | the heading | Where on the host the data lives |
| **System › Ports & firewall** | *Open the game and A2S ranges to players; keep RCON and the web GUI private.* | Which port does what |
| **System › Server files** | *Every server runs from this image, pulled once.* | The image name, and `REFORGER_SERVER_IMAGE` |
| **System › Export & import** | *Your server templates and mod lists in one file.* | What travels in the file and what does not |
| **Library › Mod lists** | *Sets of mods you reuse, ready to load into any server template.* | What a mod list is |
| **Library › Mods overview** | *Every mod you have used, and where it is used now.* | Types, tags, badges and *persist* |

Warnings you have to read before acting — deleting a server, clearing data, restoring
a backup, the passwords in an export file — are **unchanged** and still shown in full.

## Mod templates are now mod lists

*Mod template* sounded like a kind of server template, which it is not: it is a list of
mods and nothing else. It is now a **mod list** everywhere: the Library tab, its pages,
the wizard's **🧰 Mod list** picker and **Add mod list** button, Export & import, the
Mods overview badges, and the Guide.

The pages moved to `/library/mod-lists`. Bookmarks to `/library/mod-templates/…` or the
older `/mod-templates/…` forward there.

Nothing about the lists themselves changed. The export file keeps its
`mod_templates` key, so files exported by earlier versions import as before, and
earlier versions still read new ones.

## "Instance" is now "server"

The GUI called the same thing a *server* in some places and an *instance* in others. It
is **server** everywhere now: the New server dialog (*Server name*, *Game version*), the
Server files and Ports & firewall pages, the backups, the Guide, the README, and the
error messages the manager shows. For example:

> game port 2001 is already used by another server
>
> Stop the server before changing its template

The API, the database and the folders on disk (`data/instances/…`) keep their names.
