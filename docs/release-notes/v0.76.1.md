## 0.76.1: the in-app guide catches up

Documentation only. The in-app **Guide** and `docs/features.md` now describe two
recent changes:

- deleting a template that servers use (v0.76.0): who is asked, what happens to

  (v0.75.0, `rsm add-stack NAME --domain DOMAIN`).
