## What's new in 0.64.0: turn a server template into a mod list

Happy with the mods on one of your server templates? Press **To mod list** on
its row under **Library › Server templates**, and you get a new mod list with
the same mods in the same load order, version locks included
([#201](https://github.com/tubalainen/reforger-server-manager/issues/201)).

- The scenario's own mod is left out, along with any other mod that carries
  scenarios and the dependencies only those mods needed. A dependency that one
  of the kept mods still needs stays in.
- The new list is named "&lt;template&gt; mods" (or "… mods (2)" if that name is
  taken). Its description says which template it came from and which scenario
  mods were left out.
- It opens in the mod-list editor right away, so you can rename or trim it. The
  server template itself is not changed.

## Do I need to do anything?

**No.** Pull the new image as usual. No setup files changed.

## Fixed

- Setting a daily restart schedule on a server could fail with a
  "Datetime values must have timezone information" error once the image picked
  up a newer database library (sqlmodel 0.0.47). The schedule is still kept in
  the server's local time, as before.
