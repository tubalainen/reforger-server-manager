## What's new in 0.69.0: a comment on each mod in a mod list

## Do I need to do anything?

**No.** No `.env` or compose change. Pull the new image as usual. Your existing
mod lists open as before, with an empty comment on every mod.

## A comment per mod

([#216](https://github.com/tubalainen/reforger-server-manager/issues/216))

Each mod in **Library › Mod lists** now has a **Comment** box beside it:
"needed for the AI", "test before Friday", why the version is locked, anything
you want to remember about that mod.

* Up to 200 characters per mod.
* Comments are saved with the list, are part of a **Backup & restore** file,
  and show up in the list's **Change log** ("Comment on mod … set to …").
* A comment is your note on the list. Loading the list into a server template
  does not copy it, and it never reaches the server's `config.json`.

## The mod list no longer has a load order

The mod-list editor is now a plain list: each row has the mod, its comment, the
version lock and a remove button. Drag-to-reorder, the ↑ ↓ buttons, the row
numbers and **Sort A–Z** / **Sort as added** are gone. Mods stay in the order
you added them.

Load order is still set where it counts: in a server template's **Mods** step,
where you can drag rows, sort, or **Order with an AI…**. A list you ordered
before this release keeps that order, and loading it adds its mods in that
order as before.
