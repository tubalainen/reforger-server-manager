## What's new in 0.88.2: frontend packages updated for security advisories

The new daily security scan found published advisories (GitHub/npm) in the
frontend's packages. This release updates them:

- **Shipped in the GUI:** Vue 3.5.39 → 3.5.44, plus the build tooling that
  produces the GUI's files (Vite 7.3.6 → 7.3.7, PostCSS, nanoid, source-map-js).
- **Used only for development and tests:** Vitest 3 → 5 (two critical
  advisories in its worker pool), js-yaml and brace-expansion.

`npm audit` now finds nothing. The GUI itself is unchanged: same pages, same
behaviour.

## Do I need to do anything?

No, but updating is recommended.

## Updating your setup files

No compose file, `.env` setting or script changed. Pull the new manager image:

- **Linux with the installer (`rsm`):** `sudo rsm update --all`.
- **Linux VPS:** the same.
- **Linux, installed by hand:** pull the new manager image and restart it.
- **Windows:** run `.\start.ps1`, which pulls the new manager image.
