## What's new in 0.70.0: the Server Supervisor shows each server's template

The Server Supervisor's server tables have a new **Template** column: the
server template each game server was started with. A long name is cut short on
the page; hover over it to read all of it.

## Do I need to do anything?

**No `.env` or compose change.** Update as usual. On Linux:

```bash
sudo rsm update --all
```

That updates every stack and the Supervisor. On Windows, run each install's
start shortcut and the Supervisor's shortcut as usual; they pull the new image.

## Why a server shows "—" at first

The Supervisor sees no team's database, so each game server carries its own name,
template and player limit on its Docker container. A server that is already running
when you update does not have the template on it yet: it shows **—** until it is
next started (a restart, a scheduled restart, or a stop and start in its manager).

On that next start the manager recreates the server's container once, so the new
label is on it. Nothing is lost: the server's settings, saved game, mods and logs
are kept, the same as when a server is renamed.

## It is the template the server is running

The name is taken when the server starts. If a team renames the template, or
attaches another template to the server, the Supervisor keeps showing the old name
until the server is restarted, because that is still what the running server is
using.
