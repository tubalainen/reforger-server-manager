## What's new in 0.85.0: ask an AI what an error means

Closes [#254](https://github.com/tubalainen/reforger-server-manager/issues/254).

The red error lines in a server's Console now have an **✨ Ask AI** button.
It asks the AI service set up in `.env` what the error means, the likely cause
(a mod, the scenario, the config, the host) and what to do about it, or whether
it is harmless.

- **It shows only when the AI works.** An AI service must be set up in `.env`:
  `AI_ORDER_URL`, the same setting the template wizard's AI mod order uses. It
  must also be answering, and for a local Ollama its model must be downloaded.
  The manager checks this every few minutes, and again after a failed question.
  With nothing set up, nothing changes and the manager contacts no AI at all.
- **The manager builds the question itself, from its own copy of the server's log.**
  It sends the 30 lines before the error, a few after, and the template's
  scenario and mod names. IP addresses, Steam ids, BattlEye GUIDs and identity
  ids are removed first. Player names in log lines stay. The answer dialog has a
  **What was sent** section with the exact text.
- An AI can be wrong: the dialog says so. Take its answer as a lead.

The "✨ Order with an AI…" item in the template wizard (Mods step, **Sort**
menu) and the built-in **Fix order** are unchanged.

## Do I need to do anything?

No. To use it, set up an AI service as described in `.env.example` under "One-click
AI" (a local Ollama, or an OpenAI-compatible service such as Gemini or
OpenRouter). If you already set one up for AI mod ordering, the button appears by
itself.

## Updating your setup files

`.env.example` changed, but only its comments: there is no new setting. Your
`.env` needs nothing.

- **Linux with the installer (`rsm`):** `sudo rsm update --all`. It lists any
  `.env` settings you lack; there are none new.
- **Linux VPS:** the same.
- **Linux, installed by hand:** pull the new manager image and restart it.
- **Windows:** run `.\start.ps1`, which pulls the new manager image.
