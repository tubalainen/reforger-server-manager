## What's fixed in 0.75.1: deleting a template that servers still use

Reported on [#223](https://github.com/tubalainen/reforger-server-manager/issues/223):
*"I cannot delete Server Templates in Dev."* Choosing **Delete** and then **OK**
left the template in the list, with no word as to why.

The template still had a server on it. A template that a server uses cannot be
deleted, so its servers never lose their settings. The manager said so, but
two things kept the message from being seen:

- It appeared at the top of the page, far above the template you had just
  clicked.
- The list reloads every five seconds, and each reload cleared the message.

Since v0.72.0 put every existing template in Dev, most Dev templates have a
server, so this was easy to run into.

- **Delete says why it cannot be used.** For a template that servers still use,
  the item in the ⋯ menu reads *Delete (used by 1 server)* and is greyed out.
  Delete the server, or switch it to another template, first.
- **Messages stay until you close them.** A failed action on the Server
  templates page now scrolls its message into view. On that page and on
  Servers, the message stays until you close it (×) or do something else.

## Do I need to do anything?

**No.** Update the image as usual (`sudo rsm update`, or the start script on
Windows).
