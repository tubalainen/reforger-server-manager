## What's new in 0.89.0: Advanced settings you can find by their config key

A template's **Settings › Advanced settings** card was hard to search. A key
you could see in the config.json preview, such as
`VONCanTransmitCrossFaction`, sat behind a short label ("Cross-faction VON"),
and nothing on the card said which control wrote which key.

The card is rebuilt:

- **Every setting shows the config.json key it writes**, under its label. Hover
  the key to see its full path (`game.gameProperties.VONCanTransmitCrossFaction`).
- **A filter box** at the top finds a setting by its label, its key or the words
  in its help text. A setting that lives on the Server card above (BattlEye,
  view distance, …) is listed with a note saying it's there.
- **A "?" beside every setting** says what it does.
- **Grouped by where the key lives in config.json:** Game properties, Voice
  (VON), Game, Operating, Join queue, Persistence and RCON. Fast validation and
  Mods required by default used to sit under Operating, which isn't where they
  are in the file.
- **Changed settings are marked.** A setting that isn't at its default shows
  **● changed** and a **reset** link, and the card's header says how many are
  changed while it is folded.
- **Input limits match what a save accepts.** The number fields now take the
  template model's own minimum and maximum. The view distances had no limits in
  the browser, and the player save interval allowed 0 where a save needs 1 or
  more.
- The RCON settings are greyed out until an RCON password is set, the same way
  the persistence settings wait for *Configure persistence*.

No setting was added or removed, and the config.json a template writes is
unchanged.

## Do I need to do anything?

No.

## Updating your setup files

No compose file, `.env` setting or script changed. Pull the new manager image:

- **Linux with the installer (`rsm`):** `sudo rsm update --all`.
- **Linux VPS:** the same.
- **Linux, installed by hand:** pull the new manager image and restart it.
- **Windows:** run `.\start.ps1`, which pulls the new manager image.
