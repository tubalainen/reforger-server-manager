## What's new in 0.52.1 — the top menu, rebuilt

The navigation bar had quietly run out of room. With the Backup tab added in
0.52.0 there was more in that row than would fit, so every label broke in the
middle — *Server / Templates*, *Mods / Overview*, *User / Guide* — and the bar
grew to three lines of stacked words with the version number wrapping under
itself ([#175](https://github.com/tubalainen/reforger-server-manager/issues/175)).

It is now one clean row again, and it stays one row.

## What changed

- **Nothing wraps.** Tab labels are kept on a single line, always. The bar is
  back to a single 57px row instead of the 81px three-line block.
- **Shorter labels:** *Templates · Mod Templates · Mods · Instances · Backup ·
  Guide*. The full page name is still there as the tooltip, and the page
  headings are unchanged.
- **The page you are on is obvious** — the current tab is a filled pill rather
  than a slightly brighter word. It also highlights on sub-pages now: editing a
  template lights up *Templates*, an instance's page lights up *Instances*.
- **A proper menu on small screens.** Below ~990px the tabs fold into a
  hamburger menu instead of squeezing. That also fixes the bar overflowing
  sideways on a phone, which it has done for a while.
- **The live server status gives up room first.** A chip per server on a wide
  screen as before; on a narrower one it becomes a single *"1 / 3 online ·
  24👤"* that still links to the Instances page; below the hamburger breakpoint
  it steps aside entirely — the Instances page has its own status bar there.

Nothing moved pages and nothing was removed: the same six destinations are one
click away, in the same order.
