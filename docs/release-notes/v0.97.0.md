## What's new in 0.97.0: Mod size on the Servers overview

Each server on the Servers overview now shows, under its name, how much a
player has to download to join it: for example *12.30 GB of mods to download*.
Server admins can tell players up front how big the download is (#283).

- It is the Workshop size of every mod the server's template runs, plus every
  mod those depend on, each counted once. It is the same total the download
  bar uses when a server starts.
- Hover over it to see how many mods that is.
- If the Workshop could not give the size of some mods, it says *At least …*.
- Nothing is shown for a server whose template has no mods, or while the size
  is still being looked up (the first time, it takes a few seconds).

The size is looked up from the Workshop and kept for an hour, so a mod update
on the Workshop shows within the hour.

## Do I need to do anything?

No.

## Updating your setup files

No compose file or `.env` setting changed. Pull the new manager image:

- **Linux with the installer (`rsm`):** `sudo rsm update --all`.
- **Linux VPS:** the same.
- **Linux, installed by hand:** pull the new manager image and restart it.
- **Windows:** run `.\start.ps1`, which pulls the new manager image.
