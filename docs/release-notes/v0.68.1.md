## What's new in 0.68.1: no more random "error 500" on the server pages

One bug fix, for every install since v0.65.0.

## Do I need to do anything?

**No.** No `.env` or compose change. Pull the new image as usual:

```bash
docker compose pull
docker compose up -d
```

That updates both the manager and its Docker gate, which run the same image.

## The server pages now and then showed "error 500"

Since v0.65.0, the manager reaches Docker through its own Docker gate. Every now
and then a page that polls for status showed an error 500, and the manager's log
said:

```
requests.exceptions.ConnectionError: ('Connection aborted.', RemoteDisconnected('Remote end closed connection without response'))
```

The pages ask for status every 5 seconds. The gate closed a connection after
5 seconds without traffic, which is the default of the web server it runs on.
Reusing an open connection is normal, so now and then the manager sent its next
request on a connection at the very moment the gate closed it, and the request
was lost.

The gate, and the Server Supervisor's observer, now keep an idle connection open
for 10 minutes. That's well past every poll, just as Docker itself never closes
an idle connection. Nothing else changes.
