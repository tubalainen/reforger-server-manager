## What's new in 0.83.0: redownload just the template's mods, or all of them

Follow-up to [#246](https://github.com/tubalainen/reforger-server-manager/issues/246).

A server's mod folder keeps the mods of every template it has used. On one
server that was 28 GB on disk for a template whose own mods take 11 GB.

**Redownload and bake** (Settings › Mods) now asks which to delete:

- **Redownload this template's mods:** the template's mods and what they depend
  on, as before. Mods from templates the server used before stay on disk.
- **Delete all mods, then redownload:** every mod the server has downloaded,
  the leftovers of older templates too. Only the template's mods come back, so
  the rest of the space is freed.

Each choice shows how many folders and how much space it deletes. It starts on
the first choice every time you open the dialog. Either way the server stops
and starts again, and saved games are not touched. Unlike Maintenance, this
works on a running server.

## Do I need to do anything?

No.

## Updating your setup files

No compose file, `.env` setting or script changed. Pull the new manager image:

- **Linux with the installer (`rsm`):** `sudo rsm update --all`.
- **Linux VPS:** the same.
- **Linux, installed by hand:** pull the new manager image and restart it.
- **Windows:** run `.\start.ps1`, which pulls the new manager image.
