## What's fixed in 0.82.1

Follow-up to [#246](https://github.com/tubalainen/reforger-server-manager/issues/246).

- **The server page no longer jumps back to the top.** On a long tab such as
  Settings, the page scrolled back up to the tab row every few seconds, and on
  every new log line of a running server. The tab row now scrolls only
  sideways, and only when a tab badge actually appears.
- **The Mods card keeps up with the disk.** It re-reads what is downloaded
  after Maintenance clears the mods, when the server starts or stops, and when
  it comes online after downloading. **Check again** shows when it last checked.
- **A locked mod that isn't downloaded says so.** It shows "Not downloaded" next
  to its lock, instead of only "Locked at …".
- **A template that locks every mod is explained.** The card says that neither
  the daily restart nor Force update changes locked mods, and how to unlock
  them. The Force update dialog warns that it will only restart the server.
- Mod versions are also read from mods stored directly in the server's
  Workshop folder.

## Do I need to do anything?

No.

## Updating your setup files

No compose file, `.env` setting or script changed. Pull the new manager image:

- **Linux with the installer (`rsm`):** `sudo rsm update --all`.
- **Linux VPS:** the same.
- **Linux, installed by hand:** pull the new manager image and restart it.
- **Windows:** run `.\start.ps1`, which pulls the new manager image.
