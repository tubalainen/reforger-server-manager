## What's new in 0.43.8

### Max FPS now defaults to 60 on new templates (#143)
The **Max FPS** launch parameter in the template wizard now starts at `60`
instead of being blank, so new server templates cap the engine at 60 FPS out of
the box. Clear the field if you want the server to run uncapped.

Existing templates are untouched — the wizard merges a template's saved launch
parameters over the defaults when you open it, so whatever a template already
stored (including "unset") is preserved.

**Upgrade:** the manager updates itself on start, or pull
`ghcr.io/tubalainen/reforger-server-manager:latest`.

Full history: https://github.com/tubalainen/reforger-server-manager/compare/v0.43.7...v0.43.8
