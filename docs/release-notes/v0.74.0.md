## What's new in 0.74.0: game-mode categories for server templates

Server templates can now be filed under a game mode (#223). That makes a long
template list easy to scan.

- **System › Category management** lists the categories. It starts with six:
  Game Master, HQC, Conflict, COE, Escapist and Freedom Fighters. Add your
  own, rename any of them, or delete one. Deleting a category leaves its
  templates *Uncategorised*, and each of their change logs says so.
- **Pick a category** on a template's Save step. Or use **Change category…** in
  its ⋯ menu on the Server templates page. That works for a Prod template too:
  a category is only a label and never changes what a server runs.
- **The Server templates page** shows each template's category, and a
  *Category* filter shows one category (or the uncategorised ones) at a time.
- Category changes are written to the template's change log.
- Backup files carry each template's category by name. Importing onto another
  manager creates the category there if it is missing.

This completes #223: Test, Dev and Prod stages (0.72.0), version pinning
(0.73.0), and categories.

## Do I need to do anything?

**No `.env` or compose change.** Update as usual. On Linux:

```bash
sudo rsm update
```

On Windows, run the start shortcut as usual; it pulls the new image.

The six built-in categories are added on the first start. Your existing
templates start Uncategorised.
