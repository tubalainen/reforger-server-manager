## 0.80.1: the mod download bar counts only this template's mods

A fix for the download bar from v0.79.0 (#235). The bar compared everything in
the server's mods folder with the size of the template's mods. That folder
still holds the mods of any template the server ran before. So after switching
a server to a different template, the bar could read *28.84 GB of 10.47 GB ·
100 %* while the new mods were still downloading.

Each mod is stored in its own folder, named after its Workshop id. Once the
Workshop has answered with the template's mods and their dependencies, the bar
counts only those folders. Leftovers from an earlier template are ignored.
Mods the server already has count as already downloaded, so after a template
change the bar may start part-way full.

For the first few seconds, before the Workshop answers, the bar still counts the
whole folder, as before.

## Do I need to do anything?

**No.** Update the image as usual.
