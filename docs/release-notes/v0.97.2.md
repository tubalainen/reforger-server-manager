## What's fixed in 0.97.2: Security updates in the manager image

The daily security scan found known vulnerabilities in parts of the manager's
own image. They are fixed here:

- **Python 3.12 → 3.13.** Several Python vulnerabilities are fixed only in
  Python 3.13 and later, never in 3.12. The manager now runs on Python 3.13.
- **pip is updated** to the latest release when the image is built. The version
  that came with Python had several known issues.
- **gosu is gone.** The manager starts as root to prepare its data folder, then
  switches to its own unprivileged user. It used a small tool called gosu for
  that switch, and Debian's gosu was built with an old Go version that has known
  vulnerabilities. It now uses `setpriv`, which is part of Debian itself and
  gets Debian's security updates when the image is built.

Version 0.97.0 already fixed two serious problems in the system library (glibc)
of the image before it.

Nothing changes in how the manager works.

The scan also reports problems in images the manager uses but does not build:
Caddy, SteamCMD and the Arma Reforger server image. Those fixes come from their
own publishers.

## Do I need to do anything?

No.

## Updating your setup files

No compose file or `.env` setting changed. Pull the new manager image:

- **Linux with the installer (`rsm`):** `sudo rsm update --all`.
- **Linux VPS:** the same.
- **Linux, installed by hand:** pull the new manager image and restart it.
- **Windows:** run `.\start.ps1`, which pulls the new manager image.
