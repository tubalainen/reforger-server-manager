## What's new in 0.88.1: Fix order shows up whenever the list isn't sorted

v0.88.0 made Fix order sort the whole mod list: frameworks first, every mod
after what it requires, the rest by name, the scenario last. But the Fix order
button only appeared when a mod was listed **before something it requires**. A
list that broke no dependency and still wasn't in that order (for example one
sorted by Fix order in v0.87.0 or earlier) got no button. The sort was only
reachable under *Sort › Dependencies first*.

The Mods step now offers Fix order in both cases:

- **yellow**, as before, when a mod is listed before something it requires;
- **grey**, when every mod is after what it requires but the list isn't sorted.

Once the list is sorted, the bar goes away. Undo, in the note Fix order leaves,
puts the previous order back, and the bar with it.

## Do I need to do anything?

No. Open a template's Mods step and press Fix order if the grey bar shows.

## Updating your setup files

No compose file, `.env` setting or script changed. Pull the new manager image:

- **Linux with the installer (`rsm`):** `sudo rsm update --all`.
- **Linux VPS:** the same.
- **Linux, installed by hand:** pull the new manager image and restart it.
- **Windows:** run `.\start.ps1`, which pulls the new manager image.
