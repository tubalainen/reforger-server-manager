## What's new in 0.69.1: new templates start at 30 FPS with addon repair on

Two new defaults in the template wizard (#218).

## Do I need to do anything?

**No.** No `.env` or compose change. Pull the new image as usual:

```bash
docker compose pull
docker compose up -d
```

## New server templates cap the engine at 30 FPS

Under **Engine launch parameters**, **Max FPS** now starts at `30` on a new
template instead of `60`. Clear the field if you want the server to run uncapped,
or type another number.

## New server templates verify & repair their addons

**Verify & repair addons** (the engine's `-addonsRepair`) is now ticked on a new
template. On every start the server checks the downloaded mods and fixes any that
are broken or half-downloaded, instead of failing to load them. Untick it if you
would rather skip the check.

## Your existing templates are not changed

The wizard lays a template's saved launch parameters over these defaults when you
open it, so a template keeps the Max FPS and the tick box it was saved with. Only
templates you create from now on get the new values. Importing a `config.json` into
a new template also gets them, since `config.json` carries no launch parameters.
