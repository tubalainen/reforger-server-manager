## What's new in 0.81.0: a setup screen for a brand-new install

Closes [#241](https://github.com/tubalainen/reforger-server-manager/issues/241).

- **A brand-new install opens on a setup screen.** It lists the three
  downloads every server needs, each with its own button and progress bar:
  1. the **SteamCMD** image, which downloads the game's server files;
  2. the **Arma Reforger server files**, Stable, plus Experimental if you tick it;
  3. the **server runtime image** every server runs in.

  **Download everything** pulls both images at once and starts the server
  files as soon as SteamCMD is there. The downloads carry on if you leave the
  page. When all three are done, **Next: build a server template** takes you
  to the template wizard.
- **It shows once.** Finishing or skipping it ends it for good, and
  everything on it is also under System › Server files. An install that already
  has a template, a server or server files never sees it, so updating an
  existing manager changes nothing.
- **System › Server files has a SteamCMD image card.** Pull or re-pull it with
  live progress, like the runtime image. Before, Docker fetched it silently on
  the first download while the download's bar sat on "starting".

## Do I need to do anything?

No.

## Updating your setup files

No compose file, `.env` setting or script changed. Pull the new manager image:

- **Linux with the installer (`rsm`):** `sudo rsm update --all`.
- **Linux VPS:** the same.
- **Linux, installed by hand:** pull the new manager image and restart it.
- **Windows:** run `.\start.ps1`, which pulls the new manager image.
