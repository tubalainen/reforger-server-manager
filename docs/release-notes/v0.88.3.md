## What's new in 0.88.3: Apply in the JSON editor saves the template

Editing a template's config.json by hand (**Edit JSON**) and pressing
**Apply** only updated the wizard. The change was saved once you went on with
Next and pressed Save on the last step, and leaving the page before that lost
it.

Apply now saves an existing template straight away, the same way **Save
changes** does, and the bar under the step shows **✓ Saved**.

- A **Dev** template asks what changed first, as every Dev save does. Cancel
  that and the edit stays in the wizard, unsaved.
- A **new** template doesn't exist until the last step, so Apply can't save it
  yet. The bar says so: save the template on the last step to keep the edit.

## Do I need to do anything?

No.

## Updating your setup files

No compose file, `.env` setting or script changed. Pull the new manager image:

- **Linux with the installer (`rsm`):** `sudo rsm update --all`.
- **Linux VPS:** the same.
- **Linux, installed by hand:** pull the new manager image and restart it.
- **Windows:** run `.\start.ps1`, which pulls the new manager image.
