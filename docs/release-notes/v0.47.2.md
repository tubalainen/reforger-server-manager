## What's new in 0.47.2 — the persistence fields line up again

The three persistence boxes added in v0.47.0 were laid out bottom-aligned. Each
one carries a different explanatory line underneath, and *Hive ID*'s wraps onto a
second line — so that column was taller, and bottom-aligning lifted its label and
its input clear off the row the other two sat on
([#156](https://github.com/tubalainen/reforger-server-manager/issues/156)).

The row is top-aligned now, the three fields are equal width, and the two
save-session checkboxes have moved onto their own line below rather than
squeezing into a fourth column with nothing above them.

## Do I need to do anything?

**No.** Nothing changed but the arrangement of the controls. Same settings, same
values, same `config.json`.

**Upgrade:** the manager updates itself on start, or pull
`ghcr.io/tubalainen/reforger-server-manager:latest`.
