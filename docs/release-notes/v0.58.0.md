## What's new in 0.58.0: a server's page, in five tabs

The third step of the GUI rework in
[#189](https://github.com/tubalainen/reforger-server-manager/issues/189). A server's
page used to be one long scroll of eight stacked cards. Its backups, stored data and log
files sat below a log window that filled half the screen. It is now a header, a server
list beside it, and five tabs.

## Do I need to do anything?

**No.** No `.env` or compose change. Nothing about your servers, templates or backups
changes, and every button the old page had is still there.

## Every server beside the one you have open

Your servers stay listed down the left: status, scenario, and players (or *starting…* /
*stopped*). Clicking another one **keeps you on the same tab**, so going from one
server's console to another's is one click. With more than four servers the list gets a
filter box. **All servers** at the top goes back to the overview.

On a phone the list becomes a server picker above the page.

## The header

The server's name and state, its scenario and game version, and the **address players
join on**, with a Copy button. Start (or Stop and Restart) sit on the right, next to **⋯**
for renaming and deleting.

When the server needs something from you, one line under the header says what and
carries the button that fixes it: *Restart now* after a template edit, *Server files* when
they are missing, *Update server files* when a new release is out.

## Five tabs

Each tab has its own address, such as `/servers/3/console`, so a link or a reload brings you
back to the same place.

| Tab | What is on it | Where it used to be |
|---|---|---|
| **Overview** | Players, FPS, CPU and memory, each with a line for the last hour; the last six console lines; next restart, daily times, crash and reboot behaviour, last backup | the stats strip and the settings cards |
| **Console** | The live log at full height, an **All / Errors** filter, Follow, Clear, and the log and crash files to download | the log window and *Log & crash files* at the very bottom |
| **Players** | Who is on, in columns, with the count on the tab itself | the player card |
| **Saves** | Saved game backups, then the saved game on disk with the option to clear it | *Saved game backups* and part of *Stored data*, below the log |
| **Settings** | Name and game version, template, ports and join address, restart after a crash, start after a reboot, daily restarts, clearing downloaded mods and logs, deleting the server | *Edit name / branch*, *Change template*, *Edit ports*, the toggles card, *Scheduled restarts*, the rest of *Stored data* |

The Console tab's count is the number of error lines in the log window. Players shows how
many are online.

The log keeps streaming while you are on another tab, so nothing is lost by looking at
Settings for a moment.

## Smaller changes

- Settings still saves each group on its own, as before. Turning it into one form with one
  Save is the next step of #189.
- The page no longer shows the internal *Desired: running/stopped* field. Whether the
  manager brings a server back after a crash or reboot is shown in words on Overview
  instead.
- Deleting a server from its own page used to mean going back to the list first. It is
  now under ⋯ and at the bottom of Settings, with the same dialog.
- Behind the scenes the history the overview's lines are drawn from now also keeps each
  running server's own players, FPS, CPU and memory, which the Overview tab uses.
