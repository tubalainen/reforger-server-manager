## What's new in 0.97.1: Mod size on the server's own page

A server's own page now shows how much a player has to download to join it,
on the line under its name: for example
*Escapists - Merak · Stable · 12.30 GB of mods to download*. It is the same
figure as on the Servers overview (0.97.0, #283), so a server admin sees it
without going back to the list.

- It shows on every tab of the server, whether the server runs or not.
- Hover over it to see how many mods that is.
- Nothing is shown for a server whose template has no mods, or while the size
  is still being looked up (the first time, it takes a few seconds).

## Do I need to do anything?

No.

## Updating your setup files

No compose file or `.env` setting changed. Pull the new manager image:

- **Linux with the installer (`rsm`):** `sudo rsm update --all`.
- **Linux VPS:** the same.
- **Linux, installed by hand:** pull the new manager image and restart it.
- **Windows:** run `.\start.ps1`, which pulls the new manager image.
