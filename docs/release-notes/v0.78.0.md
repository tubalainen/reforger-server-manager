## What's new in 0.78.0: template named after its server, version-named copies

Follow-ups on [#232](https://github.com/tubalainen/reforger-server-manager/issues/232).

- **Name and category are on the Save step again.** v0.77.0 asked for the
  template name first, which got the order wrong. Now a new template's name
  starts as its **in-game server name** from the Settings step, and follows it
  until you type a template name of your own on the **Save** step. **Use in-game
  name** puts it back.
- **The category is guessed on the Save step,** from the in-game server name,
  the scenario, its Workshop game mode and the mod it comes from. Pick one
  yourself and the guess stops.
- **A copy of a Prod template is named after its next version.** *Copy to Test*
  on *[SWE] Grayzone - Escapist Arland [grayzone.se]* at v1 now makes
  *[SWE] Grayzone - Escapist Arland [grayzone.se] V2* instead of
  "Copy of …". A second copy becomes "… V2 (2)". Copying a Test or Dev item
  that never came from Prod gives "Name (2)". Prod mod lists work the same way.

## Do I need to do anything?

**No.** Existing templates, mod lists and copies keep their names.
