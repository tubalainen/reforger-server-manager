## What's new in 0.51.2 — the mod-template picker is where you add mods

0.51.0 let you save a mod list and load it into any server template. The control
that did it sat in the toolbar above the mod list, between *Sort A–Z* and
*Export JSON* — a row of buttons for rearranging a list you already have. That is
not where anyone looks for a way to **add** mods, so it was missed
([#166](https://github.com/tubalainen/reforger-server-manager/issues/166)).

It has moved to where the mods are added.

## Picking a mod template

The **Mods** step now has a **🧰 Mod template** picker directly under the search
box, next to the other ways of putting mods on a template:

- Choose a saved list from the drop-down — each shows how many mods it holds.
- Press **Add mod template**. Its mods are appended to the ones already there.
- The line under the picker says what pressing it would do before you press it —
  *"Adds 3 mod(s) to the 5 already here, and takes its version lock for 1 of
  them. Nothing is removed."*

**Preview / replace…** beside it opens the fuller view from 0.51.0: the whole
resulting list, and the option to **replace** the mod list instead of adding to
it (the scenario's own mods always stay). Nothing is saved until you save the
template, as before.

If you haven't built a mod template yet, the picker says so and links to the
**Mod Templates** page.

## Also fixed

- Loading a mod template said `Loaded "undefined"` instead of naming the list it
  had just loaded.

## Small print

- The toolbar above the mod list keeps only what it is for — ordering, locking,
  and JSON import/export — and is one button shorter.
- Nothing about what a mod template *is* changed: a server template still keeps
  its own copy of the mods, so editing or deleting a mod template later cannot
  change a server you have already built.
