## What's new in 0.68.0: a Players tab that shows the whole player

One bug fix, and the Players tab now shows everything the server says about a
player.

## Do I need to do anything?

**No.** No `.env` or compose change. Pull the new image as usual.

## Player names no longer swallow the IP address

([#213](https://github.com/tubalainen/reforger-server-manager/issues/213))

The Players tab showed a name like `MATT… (203.0.1…`, cut off after a few
characters with plenty of room to spare. Two things went wrong:

* **The address ended up in the name.** A real server logs a join as
  `Player #0 Name (203.0.113.9:63583) connected`, with the address in
  parentheses. The parser expected the address without them, so it kept
  `(203.0.113.9:63583)` as part of the player's name.
* **Each name had a 12-character-wide cell**, clipped with "…".

The name is now just the name, and the list is a full-width table that wraps a
long name instead of clipping it.

## More about each player

The same log lines carry more than the name, so the table now shows:

| Column | What it is |
| --- | --- |
| **ID** | The server's player id for this session. |
| **Online for** | Time since they joined, from Docker's own timestamp on the join line. Hover for the exact time. |
| **Platform** | **PC** or **Console**. |
| **IP address** | Hidden until you turn on **Show IP addresses**, so you can screenshot the tab without painting over it. Your browser remembers the choice. |
| **Identity** | The Bohemia identity id: what a template's whitelist and ban list match on. **Copy** puts it on the clipboard. |
| **Steam** | The Steam64 id of a PC player, linked to their Steam profile. |
| **BattlEye** | The BattlEye GUID. |

Players listed under **Server admins** in the server's template get an
**Admin** badge.

Every column except the name depends on the server build printing that line. A
build that doesn't shows "—" there; the name and the player count still work as
before. **PC/Console** comes from what BattlEye prints in place of a Steam id
for a console player. Bohemia doesn't document it, so if a console player
shows up as "—", please open an issue.
