## What's new in 0.91.1: Security fix in the manager image

### Fixed: zlib in the manager image

The manager image carried a zlib1g with two High-severity CVEs
(CVE-2026-76844 and CVE-2026-85091). Debian has fixed them, but the
`python:3.12-slim` base image hadn't caught up yet. The image now installs
Debian's security updates when it is built, so a fix like this one no longer
waits for the base image.

Nothing else changed in the manager.

## Do I need to do anything?

No. Pull the new image as usual.

## Updating your setup files

No compose file, `.env` setting or script changed. Pull the new manager image:

- **Linux with the installer (`rsm`):** `sudo rsm update --all`.
- **Linux VPS:** the same.
- **Linux, installed by hand:** pull the new manager image and restart it.
- **Windows:** run `.\start.ps1`, which pulls the new manager image.
