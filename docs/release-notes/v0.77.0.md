## What's new in 0.77.0: name and file a new template first

Asked for on [#232](https://github.com/tubalainen/reforger-server-manager/issues/232).

- **Name and category come first.** The template's name and its category now
  sit at the top of the wizard's first step, **Name & scenario**, instead of on
  the last one. The **Save** step shows a short summary of what is about to be
  saved, with the description.
- **The category is guessed.** For a new template, the category is filled in
  from the template name, the scenario, its Workshop game mode and the mod it
  comes from. COE (Combat Ops Enhanced), HQC (HQ Commander), Game Master (GM),
  Conflict (Campaign), Escapist and Freedom Fighters are recognised, and so are
  your own category names. The page says when it guessed; pick a category
  yourself and the guess stops.
- **The in-game server name follows the template name.** A new template's
  server name on the **Settings** step copies the template name as you type
  it. Type a name of your own there, or press 🎲 for a random one, and it stops
  following; **Use template name** puts it back.

## Do I need to do anything?

**No.** Existing templates keep their category and their in-game name; neither
is guessed or changed when you edit them.
