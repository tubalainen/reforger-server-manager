## What's fixed in 0.96.2: Kick and ban say what happened, and updates keep players on

Both found while testing on a real Linux host with a live Arma Reforger 1.9
server.

### Kick, ban and the ban list show the server's answer

Arma Reforger answers an RCON command with an empty reply, then sends what the
command printed as separate messages. The manager read only the empty reply,
so every kick and ban looked like it said nothing, and the ban list on the
Players tab was always empty.

It now reads those messages, so:

- **Ban list on the server** shows the real list, or "Server has no bans to
  list."
- A kick or ban the server refuses is shown as a failure, with the server's
  own words: for example *The server could not kick that player: Player not
  found*. Before, that showed as a success.

The Players tab also now says where bans made there go: the server sends them
to Bohemia's online services, which keep them for that server. They are still
separate from the ban list in the template.

### `rsm update` leaves the game servers running

Replacing the manager with a newer one used to stop the game servers, or not,
depending on timing. Now `rsm update` asks the old manager to leave them
running, and the new manager takes them over. Players stay connected through
a manager update.

`rsm restart`, `rsm stop` and `docker compose down` still stop the servers, as
before. Servers with *Start after a host reboot* still come back after those.

This takes effect from the update *after* this one: the manager you are
replacing now does not know the request yet, so this update may still stop
your servers.

## Do I need to do anything?

No.

## Updating your setup files

No compose file or `.env` setting changed. `rsm` itself changed and updates
itself at the end of `rsm update`. Pull the new manager image:

- **Linux with the installer (`rsm`):** `sudo rsm update --all`.
- **Linux VPS:** the same.
- **Linux, installed by hand:** pull the new manager image and restart it.
- **Windows:** run `.\start.ps1`, which pulls the new manager image.
